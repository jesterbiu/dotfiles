# Agent rules for this repo

Treat this repo as public. `home/` is generated by `sync`. Do not edit `home/` by hand: the next `sync` overwrites it.

## Audit before commit

1. Run `test/sync.test.sh`, then `./sync`.
2. Read `git status` and the full `git diff`, including new untracked files.
3. Check every changed line against the block list and the report list.
4. Report findings grouped by file. Do not stage or commit until the user approves.

### Block list

Stop and report. The change must not be committed.

- Secrets: API keys, tokens, passwords, private keys, cookies, OAuth or session files, `auth.json`, `.credentials.json`.
- Personal data: email addresses, real names, account IDs, hostnames, non-loopback IP addresses.
- The local username, or an absolute path under `/home/<user>`. Use `~`, `$HOME`, or `%h`.
- Machine state: history, sessions, caches, logs, databases, counters, trust lists, installation IDs.

### Report list

Report. The user decides.

- Machine-specific settings that can break on another machine, such as proxies, ports, and local tool paths.
- History in docs: superseded drafts, review rounds, progress notes, "was changed" wording. Docs contain the current design and lasting decisions only.
- New files under a directory entry in `manifest` that look like drafts or private notes.

## Fix at the right place

| Problem | Fix |
|---|---|
| The live file is wrong for every machine | Edit the live file in `$HOME` |
| The live file is right, but part of it must not be published | Add or change `distill/<path>` and its test in `test/sync.test.sh` |
| A file must not be published at all | Change `manifest`. List files one by one if a directory holds files that must not be published. |
